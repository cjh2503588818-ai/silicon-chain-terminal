# 硅产业链基本面终端 · Silicon Chain Fundamentals Terminal

按产业链环节组织的静态研究终端：**工业硅 / 多晶硅 / 硅片 / 电池片 / 组件** 五个大类，每个环节使用同一套模板
（快照指标 → 价格 → 成本利润 → 产量与开工 → 库存 → 进出口 → 企业与产能），另设「全链条总览」与「模型与说明」。
版面语言参考 CRU / Wood Mackenzie / BloombergNEF / SMM Research 的研究终端：高密度卡片、图表脚注标源、免责声明。

## 打开方式

双击 `index.html`（建议 Edge / Chrome，宽度 ≥ 1400px 体验最佳）。
纯静态、无外部依赖、无需联网；全部图表为手写 SVG。分享时整个文件夹打包即可。
顶部标签切换环节，`打印 / 导出 PDF` 可输出全部分页。

## 目录结构

```
index.html          版面结构（7 个页面：总览 + 5 环节 + 模型说明）
assets/theme.css    设计系统（配色 / 排版 / 卡片 / KPI / 表格 / 标签页）
assets/charts.js    自研 SVG 图表库：折线、柱状、堆叠柱、横向条形、发散条、热力图、迷你线
                    （折线自动按日期对齐不同频率的序列）
assets/app.js       各环节渲染逻辑、情形开关、标签页路由、指标卡
assets/data.js      数据快照（生成文件，勿手改）= 78 条序列 + 内部模型
preview-*.png       各环节预览
```

## 每个环节包含

| 板块 | 内容 |
|---|---|
| KPI 快照 | 6 个指标卡：主规格价格、库存、开工率、产量、利润/成本、出口（含迷你走势与环比） |
| 价格 | 环节内主要规格价格曲线（工业硅含期货，组件含分布式/集中式与中标均价） |
| 成本与利润 | 成本、价格、利润三线对照（工业硅另有主产区电价） |
| 产量与开工 | 月度产量、周度高频产量、开工率及其预测值 |
| 库存 | 环节库存水位（工业硅分港口，多晶硅分上/中/下游 + 企业热力图，硅片含企业矩阵） |
| 进出口 | 海关口径出口量（单位随原始口径标注） |
| 企业与产能 | 企业月度产量热力图（多晶硅、硅片） |
| 专有 | 工业硅：两种情形的供需平衡 **开关**；多晶硅：年度平衡表、企业库存热力图 |

## 数据来源

| 来源 | 内容 |
|---|---|
| **SMM 终端数据库**（MCP / API 直取，78 条序列） | 五个环节的现货价格、成本与利润、库存、开工率、产量、产能、进出口、组件中标均价、全球新增装机 |
| **内部平衡表与成本模型** | 工业硅两种情形的供需平衡与年度平衡表、多晶硅供需平衡（2023–2030）、成本要素（电价、硅石、电极）与现金利润、企业产量与库存矩阵、海关进出口、因子评分表 |

时间窗口：SMM 行情多数自 2025-01 起（账号可取范围）；内部平衡表覆盖 2022–2030。
单位统一在序列层面处理（如金属硅出口 吨→万吨、硅片出口 KG→万吨、电池片出口 个→亿个）。

## 更新数据

数据快照为 `assets/data.js`（`window.DATA = {...}`），字段引用见 `assets/app.js`：`D.smm.<key>`（序列）、
`D.gy / D.pc / D.cost / D.trade / D.supply / D.demand / D.inventory_co / D.score / D.derived`（内部模型）。
刷新流程：① 用 `smm_indicator_search` 找指标 ID；② `smm_indicator_data_query`（`indicator_ids` 为**逗号分隔字符串**，
单次最多 5 个）取数；③ 合并内部工作簿序列后重写 `data.js`；④ 刷新浏览器，无需改代码。
